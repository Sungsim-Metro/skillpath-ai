## 3. 피칭 교안에서 가져온 것 (참고)

- 탈락 패턴 7가지 중 우리에게 큰 것은 5번(범위 이탈)과 4번(숫자 없음)이다. 범위는 "10개 미완성보다 2개 완성", 뺀 것은 발표에서 이유를 말한다.
- 숫자: 사용자 테스트(#39)에서 "공고 30건을 손으로 비교하는 시간 vs 서비스 3분"을 직접 잰다. 숫자는 실측, 공개 자료, 근거를 밝힌 추정만 쓴다.
- 데모: `BEDROCK_MOCK`과 같은 방식으로 저장된 결과 재생 모드를 두고, 데모 모드임은 숨기지 않는다.
- 15분 배분(교안 비율표): 훅·문제 1:30 / 해결 1:30 / 데모 4:30 / 가치·근거 2:15 / 실행·차별점 2:15 / 다음·요청 1:30 / 마무리·여유 1:30. 시간이 남으면 데모가 아니라 근거(검증 수치, 데이터 출처)를 늘린다.
- 질의응답 7유형(현장 적용, 데이터 출처, 정확도·오류 대응, 비용, 기존 방식과 차이, 확장, 팀 역할)은 그 부분을 만든 사람이 답한다. 결론 → 근거 1개 → 다음 행동.
