| 주제 제공 | AWS |

주제 설명의 한 줄 정의는 "채용 공고 속의 기술 수요를 읽고 사용자가 다음에 무엇을 공부할지 근거 있게 안내하는 AI 서비스"입니다.
화려한 챗봇보다 데이터에서 추천까지 이어지는 검증 가능한 흐름을 요구합니다. 정리는 [`meetings/aws-topic-briefing.md`](meetings/aws-topic-briefing.md)에 있습니다.

## 과제가 요구한 흐름

| 단계 | 할 일 | 우리 구현 위치 |
| --- | --- | --- |
| 1 데이터 수집 | 채용공고를 가져온다 | `pipeline/` |
| 2 기술 추출 | 기술, 근거 문장, 필수/우대 구분 | `ai/` |
| 3 표현 정리 | 같은 뜻의 다른 표현을 하나로 통합 | `pipeline/` |
| 4 분석 · NCS 연결 | 직무별 요구 역량 분석, 국가직무능력표준과 연결 | `backend/`, `pipeline/` |
| 5 교육과정 추천 | AWS 교육과정을 이유와 함께 추천 | `ai/`, `pipeline/` |

그 밖의 요구:

- 확신하기 어려운 매칭은 "불확실"로 표시한다.
- AI는 문장 이해와 설명에 쓰고, 저장과 자동 처리는 AWS 서비스(S3, Lambda 등)에 맡긴다.
- 작은 입력 하나를 끝까지 처리하는 것부터 만든다.

## 발표에서 답해야 할 세 질문

1. 어떤 데이터를 분석했나요?
2. 어떤 근거로 이 역량이 필요하다고 판단했나요?
3. 왜 이 교육과정을 추천했나요?
