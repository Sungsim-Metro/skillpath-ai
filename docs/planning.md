# 기획 내용

2026-11-12 회의 반영. 회의에서 결정이 바뀌면 회의록을 먼저 남기고 이 문서를 다음 PR에서 고칩니다.
"미정"으로 적힌 항목은 아직 회의에서 확정되지 않은 것입니다.

## 한 줄 목표

Python·Linux·Git은 있지만 클라우드 경험이 없는 비수도권 컴공 4학년이, 실제 AI·클라우드 엔지니어 공고 30건 이상이 요구한 기술과
자기 기술을 비교해 무엇을 어떤 순서로 공부할지 추천 이유와 함께 3분 안에 확인한다.

- 비수도권은 발표의 컨셉이고, 공고를 지역으로 거르지는 않습니다.
- 클라우드 신입 공고가 거의 없어 신입·경력을 가리지 않고 모으며, 이 점은 한계로 적습니다.

## 왜 이 사용자인가

| 지금 벌어지는 일 | 수치 | 출처 |
| --- | --- | --- |
| 신입 자리가 줄었다 | IT·통신 대기업·중견기업 신입 공고가 전년 대비 73% 감소 (2026년 3월) | 캐치 집계, [중앙일보 2026-06-11](https://v.daum.net/v/PPvRLmmjh7) |
| 경력만 찾는다 | 채용 공고의 82%가 경력만, 신입만 뽑는 공고는 2.6% | 대한상의, [머니투데이 2026-10-24](https://www.mt.co.kr/article/2026102323324465642) |
| 비수도권은 경험 쌓기가 더 어렵다 | 구직 어려움으로 일경험·경력 부족을 꼽은 비율 비수도권 53.6%, 수도권 46.2% | 경총, [파이낸셜뉴스 2026-09-29](https://www.fnnews.com/news/202609290825283717) |
| 잘못 고른 공부는 비싸다 | 구직 청년의 취업 준비 비용 월평균 약 58만 원 | 한경협, 머니투데이 2026-10-24 |
| 기업은 사람을 못 구한다 | AI 인재 채용을 우선순위로 둔 한국 기업(64%) 중 88%가 못 구함 | AWS 의뢰 조사, [블록미디어 2024-03-14](https://www.blockmedia.co.kr/archives/483901) |

수치는 기사에서 가져왔습니다. 발표 자료에 넣기 전에 원 보고서에서 한 번 더 확인합니다.

### 미정

| 항목 | 지금 상태 |
| --- | --- |
| 공고 직접 분석 탭 | 보류 유지(11/12) |
| 로그인과 사용자 정보·대화 기록 저장 | 하기로 함. 방식과 저장 항목은 미정. 일정이 밀리면 뺌 |
| 역량 분류를 데이터에 붙이는 방식 | 분류 체계는 확정. 별칭 사전 조인인지 JSON 필드 추가인지 미정 |
| 3단 구분의 값 이름과 가중치 수치 | 수업 실습 값으로 시작해 조정. 같은 기술이 여러 구분에 나올 때 세는 방법도 미정 |
| 원본 공고 링크를 붙일 화면 | 미정 |
| 정량 지표 표와 정답셋 건수 | 10건 또는 20건. 미정 |
| 사용자 테스트 일정 | 미정 |
| API Gateway 사용 여부 | 미정 |
| 학습 상담 에이전트 구현 방식 | 팀 계정에서 Bedrock Agent 생성이 되는지 확인 뒤 결정 |

### 안 함

직무 3개 이상, 자동 수집 스케줄, 모바일 대응, 실시간 갱신, 채용공고 크롤링.
11/12에 더한 것: 공공기관·공기업 채용 데이터, 경력 연차 추출, 자격증 별도 필드, 추출 검증용 AI 추가 호출,
현직자 커피챗·링크드인 멘토 추천, 퀴즈로 역량 확인.
미룸: 공고 추천, 직무 추천.

## 숫자로 잡은 목표

| 무엇을 | 목표 | 평가 항목 |
| --- | --- | --- |
| 데이터 | 실제 공고 30건 이상, 실제 과정 20개 이상. 출처·수집일·한계 기록 | 현장 적용성 |
| 추출 정확도 | 정답지 기준 정밀도 0.85, 재현율 0.75 이상. 수업 기준은 20건에서 F1 0.7 이상 | 문제해결력 |
| 근거 | 화면에 나오는 모든 기술의 근거 문장이 공고 원문에 있음 | 문제해결력 |
| 끝까지 연결 | 공고 1건이 추천까지 가는 자동 테스트 통과, 시연 3분 이내 | 전달력, AWS 활용도 |
| 사용자 반응 | 취업 준비생 3~5명에게 보여주고 설명하게 함 | 현장 적용성 |
| 추천 성능 | 부족 기술 10개 기준 과정 검색 Top-5 적중률 | 문제해결력 |
| 가드레일 | 차단해야 할 질문 20개 중 차단 수, 정상 질문의 오차단 수 | AWS 활용도 |

지표별 목표치와 담당, 측정일을 담은 표는 아직 확정되지 않았습니다.

## 발표에서 받을 질문과 답

| 예상 질문 | 답의 방향 |
| --- | --- |
| 공고는 대부분 경력직인데 신입에게 추천해도 되나 | 경력과 상관없이 기업이 요구하는 역량은 같다. 이 서비스는 무엇을 공부할지 안내하는 추천 시스템이지 실력을 검증하는 시스템이 아니다 |
| 운영하면 비용이 얼마나 드나 | 갱신 주기와 호출 수 기준의 월 비용 추정, 줄인 방법과 결과 |
| 공공기관 채용은 왜 뺐나 | 직무를 정보통신으로 묶어 뽑아 직무별 요구 기술을 구분할 수 없다 |
