# 학습 상담 채팅 구현 계획

[상담 설계](../specs/2026-11-18-learning-chat-design.md)의 대화 예시를 Python 3.11의 단위 테스트와 Streamlit 화면 테스트로 확인한다. 실제 모드는 기존 Bedrock·DynamoDB 연결 방식을 사용하고 모의 모드는 AWS 연결 없이 실행한다.

1. `ai/chat.py`에서 원문 가드레일과 구조화된 발화 해석을 구현한다. 미지원 목표, 팀원의 작업, 학습 희망, 중단·정정 발화를 테스트한다.
2. `backend/chat_profiles.py`에서 닉네임별 프로필의 지정한 항목만 갱신한다. 빈 조회, 재접속, 동시 갱신, 저장 실패를 테스트한다.
3. `backend/chat.py`에서 프로필·사이드바·이번 상담의 사실을 합치고 요청한 단계의 백엔드 함수만 호출한다. 차단, 상태 확인, 부족 역량, 추천, 복합 요청별로 도구 호출 횟수와 답변을 확인한다.
4. `app/main.py`와 `app/chat.py`에서 대화 화면과 대시보드 렌더링을 분리한다. 첫 진입, 메시지 전송, 재실행, 사용자 전환 후의 호출과 표시 내용을 AppTest로 확인한다.
5. 설계의 다섯 대화 시나리오, 실제 SDK 호출 형식의 오프라인 테스트, 기존 앱·백엔드·AI·파이프라인 회귀 검사를 실행한다.
