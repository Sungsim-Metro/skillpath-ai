# 전체 분야·난이도 교육과정 수집 계획

**목표:** AWS Skill Builder의 무료 영어 디지털 과정을 직무·주제·난이도 제한 없이 모아 검색 평가에 사용한다.

**구조:** 공개 웹사이트가 사용하는 비로그인 GraphQL 목록을 읽는다. 검색의 100개 조회 창은 사이트의 분류값과 이름·날짜 양방향 정렬로 나눈다. 응답을 저장해 중단 뒤 이어 받고, 보고된 전체 건수와 고유 ID 수를 대조한다. 기존 KB 문서 생성기가 읽을 수 있는 별도 CSV로 내보낸다.

**기술:** Python 3.11, 표준 라이브러리, uv, unittest.

## 제약

- 무료 디지털 과정과 영어 원문 조건은 유지하고 직무·주제·난이도·상위 3개 제한을 없앤다.
- 요청은 한 번에 하나씩 최소 2초 간격으로 보내며 서버의 재시도 대기 시간을 따른다.
- 피드백 식별자, 인증 정보, 개인 학습 기록을 수집하지 않고 공개 과정 정보만 저장한다.
- 현재 서비스의 과정 표, 세부 능력 연결표, 임베딩, AWS 리소스를 보존한다.
- 없는 학습 목표와 평점은 빈 값으로 두고 수집 시각과 누락 범위를 기록한다.

## 작업

- [x] 조회 창 분할, 중복, 누락, 재개, 필드 변환을 테스트한다.
- [x] 비로그인 수집기와 응답 캐시·누락 보고서를 구현한다.
- [x] 확장 목록 1,270개를 수집하고 건수·난이도·분야·평점과 기존 목록의 중복을 검증한다. 공개 총계와의 차이 2개는 미해결로 보고한다.
- [x] 로컬 KB 문서를 만들고 수집·평가 준비 명령을 문서화한다.
- [x] 관련 파이프라인 테스트와 변경 검사를 실행한다. 커밋·배포는 하지 않는다.
