# 팀장 에이전트 구현 및 상담 구조 비교

이번 실험은 채팅 에이전트의 발화 해석을 팀장이 사용자 원문과 대조하고, 추천·검증 워커의 결과를 확인하는 구조(3번)를 대상으로 한다. 비교 대상은 팀원의 도구 호출형 상담(1번, PR #121의 `8dcf025`)이다.

1. `ai/supervisor.py`에서 보유 기술, 학습 희망, 이번 과정 요청 대상을 구분한다. 팀장은 해석을 승인하거나 근거를 붙여 한 번 재해석시키거나 사용자에게 확인한다. 검증된 과정 카드는 코드가 표시한다.
2. `backend/chat.py`의 기존 가드레일·프로필·수준 진단을 재사용한다. 기술을 지정하면 해당 직무의 수요와 해당 기술에 대한 검증 추천을 사용한다. 대상을 지정하지 않은 일반 과정 요청에는 개인 Gap을 적용한다. 팀장이 결과를 거부했을 때 카드가 표시되지 않는지 검사한다.
3. Streamlit을 `--supervised` 옵션으로 시작하면 이 구조를 사용한다. 화면 재실행이 같은 작업을 반복하지 않는지 확인한다.
4. 같은 다중 턴 문항·공통 추천 모듈·직무로 두 구조를 독립 실행한다. 차례별 대상과 행동, 결과 근거, 모델 호출·토큰·시간을 비교한다. 모의 모드의 고정 대본과 실제 모델 결과는 따로 보고한다.
