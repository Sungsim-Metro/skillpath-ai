# AWS 주제 설명 (기업별 주제 안내)

발표: 고희준 (AWS, 대학 디지털·AI 혁신 지원)
형식: 기업별 주제 안내 영상 녹취. 날짜는 녹취에 없음(OT 2026-10-24 전후로 추정, 확인 필요)
정리: 2026-11-11. 11/11 기획 검토와 11/12 멘토링의 기준 자료로 쓴다.

## 1. 한 줄 요약
"채용 공고 속의 기술 수요를 읽고 사용자가 다음에 무엇을 공부할지에 대해서 근거 있게 안내하는 AI 서비스."
핵심은 "화려한 챗봇이 아니라 데이터에서 추천까지 이어지는 검증 가능한 흐름"이다.

## 2. AWS가 제시한 5단계 흐름
| 단계 | 할 일 | 원문 표현 | 우리 담당 · 이슈 |
| --- | --- | --- | --- |
| 1 데이터 수집 | 채용 공고를 가져온다 | "고용24 같은 채용 공고에서 데이터를 가져옵니다" | 종훈 #6 #19 |
| 2 기술 추출 | 기술, 근거 문장, 필수/우대 구분 | "기술명만 뽑는 것이 아니라 어떤 문장에서 근거했는지, 필수인지 우대사항인지 구분" | 성진·일현 #9 #11 #16 |
| 3 표현 정리 | 다른 표현을 하나로 통합 | "같은 맥락의 키워드를 다른 워딩으로 … 하나로 통합" | 종훈 #13 |
| 4 분석 · NCS 연결 | 직무별 요구 역량 분석, NCS와 연결 | "직무나 산업별로 어떤 역량이 많이 요구되는지 분석하고 … 국가 직무 능력 표준과도 연결을 해보면 좋을 것" | 일현 #12, 종훈 #20 |
| 5 교육과정 추천 | AWS 교육과정을 이유와 함께 추천 | "AWS의 교육 과정을 찾아서 추천" | 종훈·성진 #14 #15 |

최종 화면: "사용자가 무엇이 필요하고 왜 필요한지 무엇을 공부해야 될지를 확인할 수 있어야 합니다."

## 3. 구체적인 요구 사항
- **근거 저장**: 예시 공고에서 Python·AWS는 필수, Docker는 우대로 뽑고 "각각의 근거 문장을 함께 저장할 수 있어야 합니다".
- **공통 요구 기술**: "수집한 범위에서 어떤 기술들이 자주 등장하는지" 뽑는다.
- **추천 이유**: "목표한 직무에서 AWS 운영이 요구되고 이 과정이 관련 내용을 다루기 때문에 이 과정을 추천합니다" 같은 설명을 붙인다.
- **Bedrock**: 표현이 일정하지 않은 문장을 읽고 기술을 추출하는 데 쓴다.
- **임베딩·벡터 검색**: 추출한 표현, NCS 항목, 교육과정 설명 사이에서 비슷한 의미를 찾는 데 쓴다.
- **불확실 표시**: "유사한 문서를 찾았다고 해서 정확한 매칭이 보장되는 것은 아니기 때문에 … 확신하기 어려우면 불확실하다고 표시가 돼야 됩니다".
- **S3 · Lambda**: "데이터 저장에는 S3", 자동 처리에는 Lambda.
- **에이전트**: "클라우드 엔지니어를 준비하려면 무엇부터 공부해야 되나요?"에 직무 수요 조회와 교육과정 검색 도구로 답을 구성한다.
- **역할 분리**: "AI는 문장 이해나 설명에 집중하고 나머지 서비스들은 AWS 클라우드 서비스".

## 4. 진행 방식 권고
1. 목표 사용자를 정한다.
2. 대상 직무와 데이터 범위를 정한다.
3. 작은 샘플로 전체 흐름을 먼저 만든다. "작은 입력 하나를 끝까지 처리하는 것부터".
4. 역할을 데이터 수집 / AI 추출·검색 / 화면 통합 / 평가·발표로 나눈다.

## 5. 평가에서 강조한 점
- "서비스가 실제로 연결돼서 잘 작동을 하는지, 분석이 타당한지, 추천이 적절한지가 중요"
- "화면이, 그래픽이, 인터페이스가 화려해도 근거가 없는 분석이면 좀 부족"
- "좋은 모델을 사용해도 마지막 추천까지 연결되지 않으면 결과가 아쉬운 부분"
- "최종 제출은 공지된 필수사항목을 충족" → 목록은 LMS 확인 필요
- 발표에서 답할 세 질문: 어떤 데이터를 분석했나 / 어떤 근거로 필요하다 판단했나 / 왜 이 교육과정을 추천했나

## 6. 우리 계획과 어긋나는 점 (11/11 검토 대상)
| 항목 | AWS 설명 | 11/10 회의 | 검토 방향 |
| --- | --- | --- | --- |
| 근거 문장 | 기술마다 저장 | 저장·표시 미정 | 기술마다 원문 문장과 집계 수치를 함께 남긴다 |
| 원문 저장 | 데이터 저장에 S3 | S3 원본 저장을 뺌 | API 응답을 S3에 보관하고 화면에는 보이지 않는다 |
| NCS 연결 | 5단계 중 4단계 | 화면 표시는 부가 기능 | 수요 상위 기술에 능력단위 이름을 붙이는 최소형 |
| 범위 | 작은 범위를 끝까지 | 직무 2개 | 클라우드를 먼저 끝까지, AI는 데이터만 추가 |
| 교육과정 검색 | 과정 설명을 임베딩해 검색 | AI가 웹에서 찾는 안도 나옴 | 무료 과정 20~30개를 표로 정리 |

녹취 전문은 저장소에 두지 않는다(2026-11-12, 저장소 공개 준비 #44). 원본은 LMS의 기업별 주제 안내 영상이다.
