# 회의록

정기 회의(화·목·일 21시)와 멘토링 기록입니다. 파일 이름은 `YYYY-MM-DD.md`, 멘토링은 `YYYY-MM-DD-mentoring.md`.
기준 자료: [`aws-topic-briefing.md`](aws-topic-briefing.md) (AWS 주제 설명 정리. 녹취 전문은 두지 않고 원본은 LMS 영상). 기획이 이 설명과 어긋나면 회의록 3번에 적습니다.
멘토링 기록에는 멘토의 실명과 발언을 그대로 옮기지 않고 조언을 요약해 적습니다(저장소 공개 준비, #44).
회의가 끝나면 메모를 Claude에게 주고 이 양식으로 정리한 뒤 `docs/meetings-YYYY-MM-DD` 브랜치로 PR을 올립니다.

## 팀원 검토 (권장)

회의록은 AI가 쓰므로 회의에서 한 말과 다르게 적힐 수 있습니다. 오해가 남지 않도록 아래 순서로 확인합니다.

1. PR을 올린 사람이 팀 채팅방에 링크를 알립니다.
2. 팀원은 자기 담당 부분(결정 사항, 할 일과 기한)을 읽고, 애매하거나 다르게 적힌 곳에 PR 댓글을 남깁니다.
3. 올린 사람이 댓글을 반영해 고칩니다. 이미 합쳤으면 후속 PR로 고칩니다.

검토는 의무가 아닙니다. 승인을 기다리지 않고 올린 사람이 합칩니다. 회의록만 바꾸는 PR에는 Claude 자동 리뷰가 돌지 않습니다.
