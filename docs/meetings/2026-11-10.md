## 1. 결정 사항
- **공고 데이터**: 로켓펀치 Open API로 시작한다. 사람인은 승인되면 추가하고, 공공데이터포털 API 3개(재정경제부·인사혁신처 채용정보, 청년 일자리 지원 서비스)는 보조로 쓴다. 잡코리아는 거절됐다. 11/13(금)까지 키가 오지 않으면 수동 수집으로 바꾼다. 크롤링은 하지 않는다.
- **대상 직무**: AI 엔지니어와 클라우드 엔지니어 2개로 한다. 신입·경력을 가리지 않고 모으고, 클라우드 신입 공고가 거의 없다는 점은 한계로 적는다.
- **NCS**: 채용 데이터로 쓰지 않는다. 기술 이름을 표준화하는 틀로 쓰고, 화면 표시는 부가 기능으로 둔다.
- **페르소나**: Python·Linux·Git은 있지만 클라우드 경험이 없는 비수도권 컴공 4학년으로 확정한다. 비수도권은 발표 컨셉이며 공고를 지역으로 거르지 않는다.
- **끝까지 연결(E2E)의 뜻**: 보유 기술 입력 → 시장과의 Gap → AWS 교육과정 추천.
- **DynamoDB**: 사용자 입력과 추천 결과도 저장한다.
- **Bedrock Agent, Guardrails**: 둘 다 필수. Guardrails는 성별·학력·인종·지역을 막고, 나이는 정상 질문이 막힐 수 있어 넣지 않는다.
- **자격증**: 역량 평가 기준으로 쓰지 않고, 추천에 관련 자격증이 있으면 곁들인다.
- **보류**: 공고 직접 분석 탭(넣게 되면 API Gateway → Lambda 로그를 시연), 학습 순서와 선수지식에 따른 과정 축약.
- **뺌**: 수요 대비 과정 공백 보기.
- **미룸**: 공고 추천, 공고 링크 연결, 직무 추천. API 이용 목적을 다시 신청해야 한다.
- **코드 리뷰**: Claude 리뷰만 받고 올린 사람이 병합한다.
- **S3 원본 저장**: 회의에서는 빼기로 했다. 다만 주제 설명과 어긋나 11/11에 다시 검토한다(5번 안건).
